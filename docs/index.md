# ReDate | 月读 项目文档

欢迎来到 **ReDate** (月读) 的开发者文档中心。

`ReDate` 是一个致力于将“碎片化信息”转化为“结构化洞见”的自动化平台。它结合了现代化的软件架构设计与最前沿的 AI 技术，为内容创作者和信息收集者提供了一套安全、稳定且易于扩展的解决方案。

## 核心支柱

- **安全为先 (Security First)**: 采用 GitHub Actions 运行业务逻辑，结合 Gost 隧道代理，将敏感凭证与代码逻辑与固定 IP 出口分离，保护系统免受攻击。
- **智能驱动 (AI-Powered)**: 集成 Google Gemini 系列模型，未来将扩展其他LLM，支持内容理解、自动化摘要生成以及基于 RAG (检索增强生成) 的长周期回顾。
- **架构优雅 (Clean Architecture)**: 严格遵循六边形架构原则，业务逻辑（Domain/Application）与基础设施（Infrastructure/Adapters）解耦，支持轻松替换数据源、存储后端或推送渠道。
- **高性能与可靠性**: 采用异步 IO (asyncio)、高性能序列化 (orjson) 以及工业级向量数据库 (LanceDB)，确保在大规模数据处理下的稳定性。
